# 子地图放这里

把「洞口 / 城镇内部 / 房间」这类**子地图**图片放进这个目录（`maps/sub/`），
然后把标签的「子地图」选成它，就能右键「进入此地图」了。

- 支持 `.png .jpg .jpeg .webp .gif .avif .bmp`，可以再分子目录（如 `maps/sub/山洞/一层.png`）。
- **这个目录里的图片不会出现在顶部的地图下拉框**，只能从标签进入；`maps/` 顶层的才是主地图。
- 加完图片重新双击 `start.bat`（或在命令行执行 `npm run maps`）刷新清单。
- 标签里记的子地图路径是相对 `maps/` 的，例如 `sub/山洞.png`。
